❌ "404 Controller not found"
   → Pastikan nama controller benar (capitalize first letter)
   → File ada di application/controllers/

❌ "Database connection failed"
   → Pastikan MySQL running
   → Periksa config di application/config/database.php
   → Jalankan setup.php lagi

❌ "URL tidak bersih (masih ada index.php)"
   → Pastikan .htaccess ada di root
   → Pastikan Apache mod_rewrite aktif
   → Periksa config.php - index_page harus kosong

❌ "Session tidak bekerja"
   → Pastikan folder tmp ada dengan permission write
   → Periksa session.save_path di php.ini
